# Day 2 — Build a Responsive Navbar

**Goal:** Build a navbar that works well on both desktop and mobile. This tests responsiveness handling and interaction state (open/closed menu), building on yesterday's layout work.

## Requirements

- Logo/wordmark on one side, nav links on the other (Home, About, Services, Contact — or similar)
- On desktop width: links shown in a horizontal row
- On mobile width: links collapse into a hamburger menu that opens/closes on click
- The active/current page link should be visually distinct (color or underline)
- Smooth open/close transition on the mobile menu — not an instant snap
- Use Tailwind utility classes only

## Not Required

- Actual routing between pages — a single page with the nav is enough, clicking a link doesn't need to go anywhere real
- A search bar or dropdown submenus — keep it to the core nav + mobile toggle
