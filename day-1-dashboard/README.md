# Day 1 — Build a Dashboard UI

**Goal:** Build a static (no real data needed) dashboard layout. This tests layout discipline, Tailwind spacing, and component structure — not API skills, that comes on Day 4.

## Requirements

- A top bar with a logo/title and a user icon or avatar (placeholder is fine)
- A stat row with at least 3 stat cards (e.g. "Total Users", "Revenue", "Active Sessions" — use realistic-looking placeholder numbers)
- A main content area showing at least one list or table of items (can be hardcoded placeholder data — an array in the component is fine)
- Must be responsive — check it at both a typical laptop width and a phone width
- Use Tailwind utility classes only — no custom CSS files
- Split it into components (don't put everything in one file) — e.g. `StatCard.jsx`, `TopBar.jsx`, `DataTable.jsx`

## Not Required (don't spend time here)

- Real API calls or data fetching — that's Day 4
- Charts/graphs — a simple number in a card is enough
- Dark mode toggle or theme switching

## Submit

1. Put your project in `submissions/<your-name>/day-1/`
2. Open a PR titled `Day 1 — Dashboard — <your name>`
3. Include a one-line PR description: what you built, anything you're unsure about
