# Day 1 — Restaurant Management Dashboard

A professional static Restaurant Management System dashboard for the Frontend Road Map Day 1 challenge.

### Built
- Responsive mobile + laptop/desktop layout
- Restaurant operations top bar + sidebar
- Four stat cards with realistic placeholder data
- Recent orders table
- Popular menu items panel
- Service status + manager insight panels
- Reusable React components and hardcoded local data
- Tailwind utility classes for UI styling; `src/index.css` contains only Tailwind entry directives
- No API calls, charts, authentication, or unnecessary features

### Run
```bash
npm install
npm run dev
```

### Build
```bash
npm run build
```
