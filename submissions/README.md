# Submissions

Each member gets one folder here, named after them, containing all 5 days of their work.

```
submissions/
└── your-name/
    ├── day-1/
    ├── day-2/
    ├── day-3/
    ├── day-4/
    └── day-5/
```

**To submit your first task:**

1. Create your folder: `submissions/your-name/day-1/`
2. Put your full project there (not just a single file — the whole runnable project: `package.json`, `src/`, etc.)
3. Commit and push to a branch, e.g. `submission/your-name-day-1`
4. Open a pull request into `main`
5. Tag the Frontend Lead as reviewer

Repeat for each day. Don't put all 5 days in one PR — one PR per day keeps review fast and keeps the scoreboard accurate as you go, rather than one huge review at the end.

See `submissions/example-member/day-1/` for a placeholder showing the expected folder shape.
